# Atannex Localization

Runs a Laravel site in several languages. It works out which language each visitor wants (from the address, their account, a cookie or their browser), builds the right links for each language, and offers a language switcher. Model fields such as titles can hold a translation for each language. It also formats dates and numbers for each language and reports text that has not been translated yet.

## Install

```bash
composer require atannex/localization
```
